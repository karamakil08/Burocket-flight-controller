# Burocket Flight Controller

This is a flight controller built around the STM32F405 MCU for model rocket applications designed to perform altitude, gyro, and acceleration measurements, fire pyrotechnics, and save flight data safely.

## Component Selection

The components selected for this project were chosen according to various measures:
* Application requirement
* Ease of supply
* Price
* Performance
* Footprint area
